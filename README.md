# ROV Bench

Self-contained Progressive Web App for self-led ROV maintainer / technician training.

**Branding** (aligned to SHKLR design kit, rev 3):
- Lucide icon: `wrench`
- Short common name: **ROV Bench**
- Dark plate: `#1a1a1a`, glyph accent: `#a78bfa`

## Curriculum (42 lessons)

Modules 1–4: Soldering, Board Rework, Hydraulics & Control, Fiber Optics  
Modules 5–7: Electrical/HV Safety & LOTO, Hydraulic Schematics, LARS & HSEQ

## Usage

Open `index.html`. Progress and notes persist locally. Install as PWA.

Videos require network. Curriculum videos remain property of their creators.
